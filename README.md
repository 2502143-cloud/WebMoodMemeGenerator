# MoodMemeGenerator

A web application that maps user-selected moods to relevant, curated memes to deliver instant emotional entertainment.

## Tech Stack
- Frontend: Angular + TypeScript
- Backend: ASP.NET Core (C#)
- Database: SQL Server

## Setup Steps

### Frontend
- Open frontend folder
- Run npm install
- Run ng serve

### Backend
- Open backend folder
- Run dotnet restore
- Run dotnet run

### Database
- Run database/SQLQuery1.sql in SQL Server Management Studio
